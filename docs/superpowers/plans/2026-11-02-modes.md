# Modes: normal, loop, shimmy

Small change (Christopher, 2026-11-02): giffy gets three modes.

| Mode | Order | Loops | Align + even |
|---|---|---|---|
| normal | 1-2-3-4 | no (no NETSCAPE block: plays once) | no |
| loop | 1-2-3-4-3-2 | forever | no (byte-identical to pre-alignment giffy) |
| shimmy (default) | 1-2-3-4-3-2 | forever | centre |

- `mode=` on `encode`, `encode_shot`, `make_gif`; `--mode` on the CLI. Default stays shimmy, so shimmy's drop-in is unchanged.
- Explicit `order`, `align`, `even` override the mode's choices (`align` defaults to a by-mode sentinel).
- Tests: `tests/test_modes.py` (default = shimmy, loop golden hashes, normal plays once in order and decodes in all three decoders, single photo, overrides, unknown mode, CLI).
